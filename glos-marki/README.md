# Tu jest Twoja marka

1. Do `korpus/` wrzuć 10-15 opublikowanych tekstów marki, jeden plik = jeden tekst (`.md` albo `.txt`). Pięć wystarczy na profil wstępny.
2. Opcjonalnie: `brief.md` ze słownikiem "tak mówimy / nie mówimy" i zasadami z brand booka.
3. Powiedz agentowi: "Wyprowadź głos marki z tekstów w glos-marki". Powstanie `glos.md`.
4. Potem: "Sprawdź ten tekst" i wklej draft.

Kilka marek (agencja): skopiuj ten folder jako `glos-marki-<klient>/`. Wszystko w `glos-marki*/` jest w `.gitignore`, więc teksty klienta nie trafią do gita.
